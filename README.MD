# 🌈 Neon Rainbow Spirograph Animation

A mesmerizing generative art web animation inspired by Python Turtle Graphics, rebuilt using **HTML5 Canvas** and **JavaScript** for smooth 60fps browser rendering.

## ✨ Features
- **Generative Spirograph:** Dynamically draws overlapping circles with smooth HSL rainbow color transitions.
- **Continuous Rotation:** Once the geometry completes, the entire structure rotates smoothly in real time.
- **Responsive Canvas:** Automatically adjusts radius and center coordinates to fit any screen size.

## 🚀 How to Run
1. Open the project folder in **VS Code**.
2. Right-click `index.html` and select **Open with Live Server**.
